# Release checklist

Use a separate game installation if you can. Back up saves you care about, and close the game before each preparer action.

1. Open the preparer and check that it found the right game folder. If using **Game folder...**, select the folder containing the game EXE. For the standard Re;Birth3 folder, the patch DLL and settings should appear under `Birth3`.
2. Run **Prepare / Resume** with prepared assets and **Fast texture conversion** enabled and story speedups off. When it finishes, launch the game and try an English scene with installed DLC if available.
3. Close the game and run **Prepare / Resume** again to check that it accepts the existing installation. If you have time, cancel a preparation and then resume it.
4. Change one setting in the app and click **Install / Update**. Reopen the preparer to check that your choice was saved. If you update the patch DLL, try **Rollback last update**; any settings you edit afterward should remain.
5. For a large story illustration, check that the image, expressions and animation appear correctly with **Downscale large story images** on. The option uses a separate prepared-assets directory; switch it off and prepare again for an original-size comparison. Report the scene and any cropping, missing images or graphics errors.
6. With **Fast texture conversion** on, try changing equipment across several characters, moving between menus, and returning to a dungeon. Check textures and portraits for corruption. For a comparison, close the game, uncheck the option, and click **Install / Update** before repeating the same route. Re-enable it afterward if it works correctly.
7. If you want to test **Apply 4GB patch**, launch the same scene afterward. If the preparer applied the patch, close the game and try **Restore original EXE**. This is separate from **Uninstall patch**.
8. With **Skip tutorials** on, try a route that normally triggers tutorials. Automatic screens and skip confirmations should be absent; Re;Birth3 and Sega should also omit the tutorial intro. Verify the following battle or map accepts controls and ordinary notices remain readable. Open Help from the menu and navigate a page. For a comparison, close the game, uncheck **Skip tutorials**, click **Install / Update**, and replay the same route. Existing saves may already mark tutorials as seen.
9. For optional Re;Birth3 testing, enable **Auto-skip story (ADV)** with **Skip Nepstation** off: Nepstation should progress its dialogue normally, and I should cancel automatic progression. Enable **Skip Nepstation** separately to test skipping the whole event and returning to gameplay. Both work with **Story fast-forward (ADV)** off. With **Skip tutorials** off, close a tutorial manually and check that story auto-skip resumes. Close the game and click **Install / Update** between setting changes.
10. When you finish testing, **Uninstall patch** removes the recognized patch DLL. It keeps settings, prepared assets, logs, and backups so you can inspect or reuse them.

Report the game, scene, installed DLC, action, settings, outcome, and exact error message. Do not upload EXEs, PACs, saves, raw captures, or game DLLs. If the preparer says it does not recognize an EXE or DLL, leave that file in place and report the message.

Re;Birth1/Re;Birth2/Re;Birth3 audio tail trimming starts on unless you explicitly disabled it. Check event and battle voices in both Re;Birth1 languages and Re;Birth2 Japanese, plus Re;Birth2/Re;Birth3 sound effects. Re;Birth2 English voices stay unchanged. Check normal playback, the following dialogue or battle, and pause/replay behavior. Voice timing tests checked individual clips. They do not cover every scene, dialogue wait or pause/replay case. Checking the full audio banks may add startup time. For a comparison, close the game and set `[Patches] TrimSilentAudioTails=0` in `rebirths-patches.ini` (`Birth3\` for Re;Birth3), then repeat the scene. Set it back to `1` after a successful comparison.
